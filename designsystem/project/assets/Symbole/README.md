# Symbole

Einfarbige Strichsymbole im 24er-Raster, Strich 2, runde Enden und Ecken, gezeichnet in Tinte #121A1F. In der App per `tint` einfärben (meist `tinte`, `tinte-2` oder die Farbe des Zustands). `karte-gelb` (Füllung #F4C20D, Kante #7A5F00) und `karte-rot` (#C62828) haben feste Farben und werden nicht eingefärbt. Bedeutungen: siehe Baustein Symbole.
